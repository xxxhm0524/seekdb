# 文件即数据库：当前实现与提交范围

本分支继承比赛基线已有的 read_csv/read_json/read_ndjson/read_parquet、glob、动态列、SQL 聚合/JOIN 和 COPY 路径。

本次补强：

- 文件读取独立执行 secure_file_priv 校验，不使用服务器日志目录白名单绕过。
- 解析真实路径，按目录边界判定权限，检查 glob 每个匹配文件，拒绝符号链接逃逸及含 NUL 的路径。
- 只读打开文件；Linux 校验实际打开的描述符路径；拒绝目录、FIFO 等非普通文件。
- 读取前后检查设备、inode、大小、mtime/ctime（Linux 包含纳秒），文件变化时报错。
- 快照上限 64 MiB、CSV 字段上限 16 MiB、字段数上限 4096，避免无界读入。
- CSV 拒绝未闭合引号、字段中间引号、闭合引号后的非法字符；空表头自动命名，重复表头按 SQL 大小写不敏感规则去重。
- JSONL 支持 BOM，拒绝根数组与重复键；保留原有字段并集和缺失字段 NULL 行为。
- 浮点推断拒绝溢出、非有限值；DATETIME 秒范围为 0–59。
- secure_file_priv 的 stat/realpath 失败按拒绝处理，避免未初始化状态或失败放行。

## 未完成项（不可宣称完整实现）

当前生产解析器仍在 resolver 阶段将文件数据构造成 VALUES。新增的有界快照不是流式扫描，**未满足题目“不得全文件物化”的通用要求**。仍需引入原生文件扫描算子，将全量 Schema 推断与执行阶段的分批取数、重扫及执行时文件变化检查分离；Parquet 列裁剪也尚未在此原型中补齐。

因此这是一版明确保留缺口的补强提交，不是 50 分全功能完成声明。

按照用户要求，本轮没有编译或运行任何测试。源码变更未经运行验证。
